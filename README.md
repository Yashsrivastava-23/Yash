# Professional Portfolio Website

A premium, modern, and fully responsive personal portfolio website built with HTML5, CSS3, and Vanilla JavaScript. Optimized specifically for database professionals and developers.

## Project Structure
```
portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── README.md
```

## How to Test Locally
1. Clone or download this repository to your local machine.
2. Open the `portfolio` folder.
3. Open `index.html` directly in any modern web browser (Chrome, Firefox, Edge, Safari), or use a local development server extension like **Live Server** in Visual Studio Code.

## Deployment Instructions (GitHub Pages)
1. Create a new public repository on GitHub (e.g., `portfolio`).
2. Push your project files to the `main` branch of your repository.
3. Navigate to your repository on GitHub and click on **Settings**.
4. In the left sidebar, click on **Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose the `main` branch and click **Save**.
